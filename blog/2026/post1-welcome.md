# Welcome

Hi, and welcome to my personal website!

Well this is actually the second version of my personal website. The old one will be
archived on my [GitHub]() by the time this new one goes out.

The main feature of this new website is the page you are on right now, the entry page.
It displays blog posts and other entries written in [Markdown](https://en.wikipedia.org/wiki/Markdown). This makes writing posts
and entries really easy compared to the old website.

If you don't like this beautiful entry page, you can always use your browsers reader view instead.
You might need to refresh the page for it to appear.

## Options

The site options can be found in the site header when expanded. If your browser keeps cookies
over sessions the options should stay the same any time you visit this site. 

### Themes

The website has five different themes:

- Three of [Catppuccin's](https://catppuccin.com/) pastel colour palettes.
  - Mocha (dark)
  - Frappé (medium)
  - Latte (light)  

- Saunakatti theme.
  - A more personalised and experimental theme with a background image.

- Legacy Light from my old website.
  - light brown, sandy colours, combined with the colours from Catppuccin Frappé. 

### Fonts

The website has three font choices, all [Nerd Fonts](https://www.nerdfonts.com/):

- Noto Sans Nerd Font
  - A basic sans-serif font.

- JetBrainsMono Nerd Font
  - A monospace font, used in codeblocks.

- OpenDyslexic Nerd Font
  - _"Designed specifically to alleviate reading errors caused by dyslexia."_

I guess I'll write an introduction to the site in general here.

So welcome to my personal corner of the web. The short story about this site is that it was
supposed to just host some links, but got a bit out of hand. (Although it might just end up
hosting links either way.) This became quite a learning project into CSS, HTML and JavaScript.
I also ran into Neocities, which has been a good source of inspiration. Creating a personal social
media page from scratch is certainly more fun than playing completely by the rules of massive
megacorporations. And the best part is that anyone can make one since the main languages to make
static websites, CSS and HTML, are easy to learn.

As you might be able to tell by the site address, this site is not hosted on Neocities,
but on GitHub (owned by a megacorporation btw :D). The source code for this site is completely
public and can be found on my GitHub. More documentation about the site and other stuff can be
found in the Documentation (not made yet).

I personally use Firefox based browsers and the website has them in mind.
It should work on Chromium based ones as well, although there may be visual differences.
It's also worth noting that site usability with larger screens comes before smaller ones
like mobile devices.

The default theme is dark but if you'd prefer a light theme, it can be switched on from the menu,
accessed by clicking the three lines in the top-right corner.
